🧮 Calculator 

A user-friendly calculator built using Python and Tkinter.
It’s designed to handle everyday arithmetic operations through a clean graphical interface.

✨ Features
Easy-to-use graphical interface
Supports basic arithmetic operations:
Addition (+)
Subtraction (−)
Multiplication (×)
Division (÷)
Clear button (C) to reset calculations
Handles errors gracefully (e.g., invalid inputs or division by zero)
🛠️ Technologies Used
Python
Tkinter (built-in Python GUI library)

📁 Project Structure
calculator/
│
├── calculator.py   # Main application file
├── run.bat         # Optional Windows launcher

🧩 Interface Overview

The calculator includes:

Numeric buttons (0–9)
Operation buttons (+, −, ×, ÷)
= button to compute results
C button to clear the screen

The layout is simple, making it suitable for beginners learning GUI development.
